# 國家太空中心 六大模組 闖關學習

航太工程 × 專業英文 —— 給技術型高中學生的互動闖關網站。
內容對齊《專業英文暨職場英文》學習手冊，涵蓋福衛五號、福衛七號、獵風者與齊柏林衛星（福衛八號）。

## 六大模組

| MOD | 主題 | 互動 |
|---|---|---|
| 01 | 姿態控制 AOCS | 選對裝置止旋，再用反應輪把自旋歸零 |
| 02 | 整測廠房試煉 AIT | 安全互鎖＋把音震測試調到飛行狀態 |
| 03 | 軌道冷熱盾 TCS | 向陽／地影各找出正確的熱控組合 |
| 04 | 太空鷹眼 Optical | 依任務判斷要黑白、彩色還是融合影像 |
| 05 | 掩星氣象 RO | 從彎曲角與延遲反推天氣 |
| 06 | 過境通訊 Pass | 10 分鐘內依正確順序完成四項通聯 |

每個模組：**概念 → 英文術語（可點讀發音）→ 動手操作 → 2 題測驗**，通過才解鎖下一個。
測驗難度依前一模組表現自動調整，全部完成可領取分級電子證書。

**設計原則**：每個操作都要做出可能出錯的判斷，而且錯了會告訴你為什麼錯 —— 不是點一點就過。
